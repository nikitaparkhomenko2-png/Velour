# AutoGlass — iPhone car dashboard

Готовая PWA-папка под Safari/iPhone. Интерфейс сделан по мотивам присланного ролика: тёмный премиальный экран, большие скруглённые карточки, стекло/blur, автомобиль сверху, номер, штрафы, быстрые сервисы, цена, топливо и расходы.

## Как пользоваться
1. Открой `index.html` в браузере или залей папку на Netlify/Vercel/GitHub Pages.
2. На iPhone в Safari нажми «Поделиться» → «На экран Домой».
3. Любая надпись с данными редактируется обычным нажатием: курсор появляется прямо в тексте.
4. Никаких карандашиков и подсказок «нажмите для изменения» нет.
5. Фото автомобиля меняется нажатием на само фото. Выбранное фото сохраняется на устройстве.
6. Все введённые значения сохраняются в localStorage.

## Фото
По умолчанию используется фотография Mercedes-Benz G-Class из Wikimedia Commons, опубликованная автором в public domain:
https://commons.wikimedia.org/wiki/File:Mercedes-Benz_G-Class.jpg

Для своего автомобиля просто нажми на фото и выбери снимок из галереи iPhone.

## Важно
Это PWA-прототип, а не опубликованное в App Store нативное приложение. Для настоящего App Store приложения можно затем перенести этот интерфейс в SwiftUI.
